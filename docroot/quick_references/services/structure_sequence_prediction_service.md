# Structure Sequence Prediction Service (ProteinMPNN)

## Overview
The Structure Sequence Prediction Service predicts amino acid sequences that are compatible with a given protein backbone structure using [ProteinMPNN](https://www.science.org/doi/10.1126/science.add2187). This "inverse folding" approach is widely used in protein design to generate candidate sequences that are likely to fold into a desired target structure. The service accepts a backbone structure and returns one or more predicted sequences.

## Parameters
Provide a protein backbone structure, then specify an output folder and output name. See the service input form for the full set of parameters.
