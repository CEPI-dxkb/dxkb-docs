# Stability Prediction Service (ThermoMPNN)

## Overview
The Stability Prediction Service predicts changes in protein thermodynamic stability using ThermoMPNN-D. Given a protein structure, ThermoMPNN estimates the effect of point mutations on stability (ΔΔG), enabling rapid in silico screening of stabilizing and destabilizing mutations across a protein.

## Parameters
Provide a protein structure, then specify an output folder and output name. See the service input form for the full set of parameters.
