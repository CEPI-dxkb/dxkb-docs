# FrustraMPNN Service

## Overview
The FrustraMPNN Service predicts local energetic frustration for a protein given a PDB structure. Frustration analysis highlights residues and interactions whose local energetics deviate from an optimally folded state — information that is often associated with functional sites, binding regions, and conformational flexibility. The service accepts a protein structure and returns per-residue frustration predictions.

## Parameters
Provide a protein structure (PDB), then specify an output folder and output name. See the service input form for the full set of parameters.
