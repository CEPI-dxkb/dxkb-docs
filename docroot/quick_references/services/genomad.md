# Genomad Service

## Overview
The Genomad Service executes all modules of the [geNomad](https://portal.nersc.gov/genomad/index.html) pipeline for plasmid and virus identification from FASTA formatted contigs. geNomad identifies mobile genetic elements — viruses and plasmids — in assembled sequence data and provides taxonomic assignment for the identified viral genomes.

## Parameters
Provide FASTA formatted contigs, then specify an output folder and output name. See the service input form for the full set of parameters.
